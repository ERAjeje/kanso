        return () => clearTimeout(timer)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Form input → React state | User-supplied text enters the application memory space |
| React state → PouchDB (IndexedDB) | Data persisted to browser storage |
| PouchDB sync → CouchDB (HTTPS) | Data transmitted over network with JWT auth |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
